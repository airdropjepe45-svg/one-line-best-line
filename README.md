## How it works

`main.ts` writes the line above to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default). Before writing it validates the gate: 1–240 characters, valid UTF-8, a single line, and not only white space — if the line ever failed a check the program exits non-zero and writes nothing.
